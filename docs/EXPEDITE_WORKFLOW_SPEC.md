# EXPEDITE_WORKFLOW_SPEC.md — 一键催单工作流规格

> 状态：**SPEC（定稿）** — 本期只定义 UX 工作流与前端数据组织，**不定义、不调用任何不存在的催单发送 API**。
> 证据基线：旧系统子设计师端**无催单发送 API**（[VERIFIED] reminderMessage.do 全套接口仅 列表/详情/已读/备注）；催单由客服侧发起，经语音外呼+短信触达（[VERIFIED] 计费统计）。

## 1. 能力边界声明（P0-F3）

### A. 旧系统已有能力（保持读取兼容）

| 能力 | 旧系统接口 | 新系统处置 |
| ---- | ---- | ---- |
| 催单消息列表 | getReminderMessageNew.do | Legacy Adapter 读取 |
| 消息详情 | reminderByIdNew.do | Legacy Adapter 读取 |
| 单条已读 | updateIsReadReminderNew.do | 写操作：Phase 2 接入（需用户确认） |
| 全部已读 | updateIsReadAllReminderNew.do | 同上 |
| 备注 | updateRemark.do | 同上 |
| 未读计数（全局 Badge） | getReminderNoticeCountNew.do / getReminderMessageNoReadNew.do | 首页卡片 + 顶栏 Badge |

### B. 新系统拟增加能力（本期设计）

- **待催单聚合视图**：以订单状态（未反馈=2 / 设计中超截稿前 N 小时 [INFERRED 阈值待用户确认]）聚合出"应收催单的订单"清单
- **订单上下文关联**：每条催单消息内联显示所属订单的关键字段（品类/设计费/截稿/店铺），点击直达订单详情 Drawer
- **批量选择**：复用 BATCH_ORDER_OPERATION_SPEC 的选择器
- **催单文本生成**：按模板把勾选订单渲染为文本
- **订单号批量复制**：复用批量复制组件
- **催单模板**：本地可编辑模板（变量占位 `{店铺}` `{订单号}` `{品类}` `{截稿时间}` `{设计费}`）
- **快捷操作**：一键复制/逐条复制/导出清单
- **记录**：本地操作日志（复制了什么、何时），Phase 2+ 再议服务端同步

### C. 明确不做（本阶段）

- ❌ 假定存在"一键催单发送"旧系统 API —— **不存在** [VERIFIED]
- ❌ 任何自动发送行为（短信/语音/IM）——属新增服务端能力，需另行立项设计业务通道（Phase 2+ 与客服流程对接后才有意义）
- ❌ 调用已读/备注类写接口 —— Phase 2 接入前需用户确认写权限风险

## 2. 工作流定义

```text
筛选（我的订单：状态=未反馈 / 距截稿<阈值）
   ↓
勾选订单（批量选择器，跨页保持）
   ↓
批量操作栏：[生成催单文本] [复制订单号 ▾] [加入催单清单]
   ↓
催单预览抽屉（Drawer）
   ├─ 模板选择 + 变量自动填充（逐单展开预览）
   ├─ 一键复制全部 / 逐单复制
   └─ 明确提示：复制后由你在既有沟通渠道自行发送（本系统不代发）
   ↓
记录（本地操作日志：时间/单号/模板/动作）
   ↓
（Phase 2+ 预留）发送通道接入点：适配器接口留空，UI 不隐藏
```

## 3. 催单模板（初始内置 2 个，本地可编辑）

```text
【模板A·温和】
店铺：{店铺}
订单：{订单号}（{品类}）
截稿：{截稿时间}
提醒：以上订单待反馈，请尽快安排设计反馈哦~

【模板B·紧凑】
{订单号}（{品类}，截稿 {截稿时间}）待反馈，麻烦尽快处理！
```

- 变量缺失时显示 `<缺失:字段名>` 而非空白（防漏发信息）。
- 模板存储：localStorage（Phase 1），Phase 2+ 迁移服务端。

## 4. 催单中心信息架构（为 NEW_INFORMATION_ARCHITECTURE.md 提供）

```text
催单中心
├── 待我处理的催单（旧系统收件箱读取：列表+Badge，只读）
│     └─ 每条内联订单上下文卡（品类/设计费/截稿/店铺）→ 点击开订单详情 Drawer
├── 我要发起的催促（新增：本地聚合视图 + 文本生成，不发送）
│     ├─ 待催单清单（筛选器+批量选择）
│     └─ 催单工作流（§2）
└── 催单记录（旧系统语音/短信触达记录读取 myYuyinList.do + 本地复制日志）
```

## 5. 验收标准

- [ ] 首页待催单卡片数量 = 订单中心"未反馈"Tab 计数（同一数据源 getOrderList countInfo）
- [ ] 勾选 3 单生成模板文本，变量全部正确填充，缺失变量显式标注
- [ ] 全流程无任何写请求发往旧系统（DevTools 网络面板验证仅 GET）
- [ ] 旧催单收件箱在新系统可读、Badge 数字与旧系统一致
