# NEW_UI_UX_DIRECTION.md — UI/UX 规范（可开发定稿）

> 状态：**DEVELOPMENT READY** — 2026-09-20 定稿。从"设计关键词"升级为带具体数值的规范。
> 视觉基调：现代 / 简洁 / 克制 / 大气 / 高信息密度但不拥挤。参考 Linear、Vercel、Notion、飞书、Tabler 的气质，**不复制任何产品**。

## 1. 布局骨架（数值化）

| 项 | 规范 | 说明 |
| ---- | ---- | ---- |
| 页面内容最大宽 | 1440px 居中（>1600 屏左右留白） | 防超宽拉伸 |
| 侧栏宽 | 收起 64px / 展开 220px | 可折叠，记忆状态 |
| 顶部栏高 | 56px，白底底边 1px 分隔线 | 全局搜索框常驻 |
| 内容区 padding | 24px（卡片间距 16px） | 统一节奏 |
| 栅格 | 12 栏 / 16px gutter | 聚合卡等宽分布 |

## 2. 色彩系统

| 用途 | 值 | 备注 |
| ---- | ---- | ---- |
| 主色（品牌/主按钮/选中） | `#4F46E5`（靛蓝 Indigo-600） | 替代模板默认绿，克制专业 |
| 中性文字 | 主 `#1F2328` / 次 `#57606A` / 弱 `#8B949E` | GitHub 灰阶 |
| 背景 | 页面 `#F6F8FA` / 卡片 `#FFFFFF` | 浅灰底白卡，弱化边框 |
| 边框 | `#D0D7DE`（1px，仅卡片与表格线） | 不用阴影堆层次 |
| 成功/进行 | `#1A7F37` | 订单完结/审核通过 |
| 警示/待办 | `#9A6700` | 待接单/待催单 |
| 危险/异常 | `#CF222E` | 审核不通过/超时/异常单 |
| 中性状态 | `#57606A` | 已完结灰显 |

> 状态色用于**文字与左侧 3px 竖条标记**，不大面积铺色（区别于传统 ERP）。

## 3. 字体与密度

- 字体栈：`Inter / -apple-system / "PingFang SC" / "Microsoft YaHei" / sans-serif`；等宽（单号）：`JetBrains Mono / Consolas`。
- 字号：页面标题 16px/600、卡片标题 14px/600、正文 14px/400、辅助 12px、表格 13px。
- 行高 1.6；表格行高 44px（紧凑 38px 可切）。
- 圆角：卡片 8px、按钮 6px、输入框 6px、Tag 4px（**不用大圆角**，保持工作台干练）。
- 阴影：仅 Drawer/Modal/Popover 用 `0 8px 24px rgba(31,35,40,.12)`；卡片**不用阴影**，靠 1px 边框。

## 4. 核心组件规范

| 组件 | 规范 |
| ---- | ---- |
| 按钮 | 主=主色实底；次=白底灰边；危险=红边红字（非红底）；禁用=40% 透明。高度 32px（表格内 28px） |
| 表格 | 表头 12px/600 灰底 `#F6F8FA`；斑马纹不用，悬停行 `#F6F8FA`；行尾操作列固定右侧；多选列 44px；行颜色标记沿用旧 backgroundColour 语义 → 行首 3px 竖条 |
| 状态 Tag | 浅底+深字（如 成功=`#DAFBE1/#1A7F37`）；仅 4 种状态色，禁止彩虹 Tag |
| Drawer（订单详情） | 宽 720px（版次/文件 Tab 内容多）；右滑入；头部固定订单号+状态+复制按钮 |
| Modal | 宽 480-640px；仅确认类操作（改价/取消订单迁移时用） |
| Search | 顶栏全局+页内筛选两种；防抖 300ms；`/` 快捷键；空结果给快捷 chips |
| Toast | 右上 3.5s；复制类操作必须反馈（已复制 N 个订单号·格式） |
| 空状态 | 线性插画（黑白灰）+ 一句引导 + 一个主操作按钮 |
| 加载 | 卡片=骨架屏；表格=行骨架 3 行；按钮=内联 spinner；**禁止全屏遮罩转圈** |
| 错误 | 表格区错误→区域级重试卡；表单错误→字段下 12px 红字；网络错误→Toast+重试 |

## 6. 明确避免（红线）

- 传统 ERP 蓝、大面积渐变、彩色渐变大屏、十几个统计图、三级菜单、行内无限弹窗。
- 表格内嵌超 2 行文本（长文本入 Drawer）。
- 无反馈的操作（一切写操作/复制必须有 Toast 或状态变化）。

## 7. 与实现的映射

- 以上数值均可直接落为 `src/style/` 设计令牌（CSS 变量：`--brand:#4F46E5; --bg-page:#F6F8FA; …`）+ Tailwind theme 扩展；Element Plus 主题变量同步覆写（`--el-color-primary` 等）。
- Phase 1 验收时按 §4 组件规范逐组件核对。
