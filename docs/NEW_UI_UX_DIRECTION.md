## 总体方向

> 简洁、大气、现代、克制、高信息密度但不拥挤。

## 明确避免

- 传统 ERP 蓝色模板
- 大面积渐变
- 过多彩色卡片
- 无意义的数据大屏 / 十几个统计图
- 复杂三级菜单

## 一键催单交互（研究方向）

```text
筛选待催订单 → 批量勾选 → 一键催单 → 成功/失败反馈 → 记录操作
```

## 批量订单号复制（研究方向）

支持逐行 / 顿号分隔 / 逗号分隔，一次点击复制到剪贴板；可扩展：复制订单号 / 催单文本 / 纯文本 / 带分隔符文本。
