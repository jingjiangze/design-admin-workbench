# HOME_WORKBENCH_SPEC.md — 首页工作台规格

> 状态：**SPEC（定稿）** — 2026-09-20。首页不是普通 Dashboard，是"查单入口 + 今日工作聚合"。
> 数据源全部来自已取证接口（getOrderList countInfo / 通知计数 / 无新增旧 API）。

## 1. 三层结构定义

### 第一层：全局查单（页面视觉中心，置顶）

| 搜索维度 | 匹配字段（旧 API 已有 [VERIFIED]） | 说明 |
| ---- | ---- | ---- |
| 订单号 | getOrderList.ordernum | 支持粘贴后自动去空白；命中唯一 → 直接开详情 Drawer |
| 批量订单号 | ordernum 多值（换行/顿号/逗号分隔自动识别） | 复用 BATCH_ORDER_OPERATION 的分隔解析；结果进多选列表 |
| 客户/店铺 | shop / kehu_name / membername | 前端对当页+搜索接口结果过滤；联动 store |
| 手机号 | **注意**：列表无手机号字段，PII 仅在详情 ERP 快照 [VERIFIED] → Phase 1 先按"订单号/客户/店铺"出结果；手机号搜索标注"进入详情后核对"占位，Phase 2 若服务端支持再加 | 诚实边界，不伪造能力 |
| 模糊查询 | ordernum contains + shop contains | 前端 debounce 300ms |

- 搜索结果区：紧凑表格（最多 20 行）+ "在订单中心查看全部"链接。
- 空结果：展示常用快捷筛选（见第三层）而非空白。

### 第二层：待处理聚合卡（4 张，横向）

| 卡片 | 数据源 | 点击去向 |
| ---- | ---- | ---- |
| 待处理 | countInfo.wait + nofeedback（[VERIFIED] getOrderList） | 订单中心·待接单/进行中 |
| 待催单 | 本地聚合：state=2 且距 timeneeds < 阈值（阈值默认 24h，用户可调 [INFERRED 待确认]） | 催单中心·我要催的订单 |
| 异常 | isqll≠未申请 计数 + countInfo.badordercount + flowmarker | 订单中心·异常与申诉 |
| 今日订单 | createtime 为今日的行计数 + 本日单量（memberCenter 首页已有此统计 [VERIFIED]） | 订单中心·全部（今日筛选） |

- 卡片显式数字 + 环比箭头（环比 Phase 1 可先不做，占位）。
- 计数为 0 的卡片降透明度但不隐藏（保持布局稳定）。

### 第三层：品类快捷入口

**原则：428 个原始品类绝不整体平铺在首页。**

- 业务分组（映射 428 goodsid，分组清单由 categoryService 提供，本地静态配置可调）：

| 分组 | 示例 goodsid（实测样本） |
| ---- | ---- |
| 名片卡类 | 名片 548890581、PVC名片 1717812924、普通特种纸名片 1905267588、对裱名片 1948177609 |
| 宣传物料 | 宣传单 548890565、海报 548890583、纯文字海报 1859137380、展架易拉宝 548890588 |
| 印刷标签 | 不干胶 548890572、水晶标 1874477630、即时贴 1866056430、联单 1628198756 |
| 办公礼品 | 纸杯 892386611、定制杯垫 1876680760、台历 548890575、会员卡 548890573 |
| 其他 | 分组外全部 + 搜索兜底 |

- 每个分组显示：图标 + 组名 + 该组今日/本周单量（前端按订单行 goodsid 聚合）。
- 分组点击 → 订单中心按该组 goodsid 预筛选；组内展开显示具体品类 chips。
- **常用**：本地记录最近 8 个使用的 goodsid（localStorage）；**搜索**：输入即时过滤 428 项（分类+名称+keywords 三字段匹配，keywords 如"名片，明信片，名牌，铭牌"来自详情取证 [VERIFIED]）。

## 3. 交互与状态

- 加载：卡片骨架屏（非转圈）；搜索防抖；网络错误卡片显示重试按钮（不做全局遮罩）。
- 空态：搜索无结果 → "试试品类快捷或常见筛选" + chips；无待催单 → 卡片打勾样式"今日无临期订单"。
- 快捷键：`/` 聚焦搜索框；`Esc` 清空并失焦。
- 移动端（≥768px 自适应）：卡片 2×2，品类分组横向滚动。

## 4. 验收标准

- [ ] 粘贴 3 个订单号（混合分隔符）→ 正确解析并显示 3 行结果
- [ ] 待催单卡片数 = 催单中心"我要催的订单"初始列表数（同一聚合逻辑）
- [ ] 428 品类不在首页整体渲染；搜索"名片"命中分组与 chips（含 keywords 匹配"明信片"）
- [ ] 首页全部请求经 service 层，无旧 URL 散落
