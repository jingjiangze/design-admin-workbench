## 设计约束

- 不照抄原后台菜单；按真实业务工作流重新组织
- 首页直接查单（订单号 / 客户 / 手机号 / 多订单号 / 模糊查询）
- 高频功能减少点击次数，低频功能不干扰主工作流
- 避免传统 ERP 蓝色模板、大面积渐变、无意义数据大屏、复杂三级菜单
