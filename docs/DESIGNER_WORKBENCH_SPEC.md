# DESIGNER_WORKBENCH_SPEC — 设计师工作台信息架构（定稿）

> 状态：**SPEC FINAL** — 2026-09-20（Phase 1B）
> 定位：**设计师每天打开的工具**，不是功能很多的管理后台。
> 设计 tokens：白色/浅灰底/深色文字/单一品牌色/少阴影/细边框/紧凑表格/大搜索框。

## 1. 一级导航（6 项定稿）

| 导航 | 路由 | 职责 |
|------|------|------|
| 工作台 | /welcome | 首页：三件事一眼看清 |
| 订单 | /order | 订单工作表 + 详情 Drawer |
| 催稿 | /expedite | 待处理催稿 / 我要催稿 / 催稿记录 |
| 收入 | /income | 日/周/月收入 + 反查订单 |
| 品类 | /category | 品类 + 商品金额规则 |
| 账户 | /account | 账户信息 + 金额规则导入导出 |

命名规范：全站"催稿"（禁"催单"）；无"数据中心"（收入页取代）。
消息定位不变：顶栏全局能力（Badge），非侧栏项。

## 2. 首页结构（自上而下）

```text
大搜索框（搜订单 / 客户 / 店铺 / 批量订单号）
4 统计卡：待处理 | 待催稿 | 今日订单 | 本月收入
今天需要关注：即将截稿 N 个 / 尚未反馈 N 个 / 金额未定义 N 个（各带跳转）
最近订单（≤8 行紧凑表：订单号/品类/状态/金额/截稿 → 点击开 Drawer）
常用品类（名片 / PVC / 宣传物料 / 其他 → 点击进订单页带过滤）
```

禁止：大面积图表、复杂 BI、几十个统计卡片、三级菜单、大量装饰。

## 3. 全局搜索行为

| 输入形态 | 识别 | 行为 |
|----------|------|------|
| 单个订单号（TT_ 前缀或纯数字） | 精确查单 | 直接打开订单 Drawer |
| 客户/店铺/关键词 | 模糊 | 跳订单页并带 keyword 过滤 |
| 多行 / 顿号 / 逗号 / 空格分隔的多个订单号 | 批量 | 跳订单页批量过滤（formatOrderNos 四分隔符） |

快捷键：`/` 聚焦搜索、`Enter` 执行、`Esc` 关闭浮层、`?` 快捷键帮助。快捷键不过多。

## 4. 订单工作表

默认列：`□ | 订单号 | 品类 | 店铺 | 类型 | 设计费 | 状态 | 截稿时间 | 操作`
可选列（默认关）：加急 / 版数 / 设计进度。默认不过宽。

状态筛选（6 视图，不暴露旧 state 数字）：全部 / 待接单 / 进行中 / 待审核 / 已完成 / 风险。

## 5. 订单详情 Drawer（右侧）

区块顺序：订单号（+复制）· 状态 → 基础信息（品类/店铺/订单类型/截稿）→ 金额区（**原始金额 / 统计金额并排明确区分** + 金额来源解释）→ 版次 → 文件 → 聊天 → 校对 → 历史。
`Esc` 关闭。所有数据经 Domain Service（order-detail.ts），UI 零 legacy 引用。

## 6. 催稿中心（三 tab）

| tab | 内容 | 动作 |
|-----|------|------|
| 待处理催稿 | 旧系统催稿消息卡片（品类/订单号/截稿/备注） | 查看订单（开 Drawer）/ 标记已读 |
| 我要催稿 | 待催稿订单列表（筛选+勾选） | 生成催稿文本 → 复制（**不发送**） |
| 催稿记录 | 已生成/已复制的历史（本地留存） | 重新复制 |

催稿文本模板：温和 / 简洁 / 自定义；变量缺失显式 `<缺失:xxx>`，禁止静默留空。
批量复制：四分隔符（换行/顿号/逗号/空格），复制后提示"已复制 N 个订单号"。
**禁止**：短信/语音/微信/IM 自动发送。

## 7. 收入页

卡片行：本日 / 本周 / 本月 / 已完成订单 / 金额未定义（点击跳金额规则）。
口径切换：我的统计（默认突出）⇄ 系统金额。
品类分布（今日+区间）：品类名 + 单数 + 金额 → 点击反查订单列表 → Drawer。
未定义提醒条："N 个订单未计入收入统计 [去设置]"。

## 8. 品类中心

- Tab 1 品类订单：品类卡（今日 N 单 / 本月 ¥xx / 我的金额 ¥x）→ 点击进订单页带品类过滤。
- Tab 2 金额规则：按品类分组商品卡；搜索（名称/goodsid/subGoodsid/keywords，基于 Phase 0 keywords 命中如 名片→PVC名片/明信片/名牌/铭牌）；每行 系统金额 | 我的金额 对照；未设置 ⚠ 醒目；[设置金额] 弹窗 / [批量设置] / [恢复系统金额]。

## 9. 账户页

账户信息卡 + 金额规则管理入口：导出金额规则（JSON 下载）/ 导入金额规则（预览：新增 x 覆盖 y 跳过 z）。

## 10. 交互基建

- 全局搜索常驻顶栏（所有页面可见）。
- Drawer 内复制订单号：`C` 键（Drawer 打开且有订单时）。
- 所有页面数据经 Domain Service；Mock/Real 由 VITE_LEGACY_API_ENABLED 统一切换。
